# 便签本录屏回归

根据用户提供的 9 秒录屏核对：拖动的卡片半透明，下面的文字穿透；封面色取排序索引，落位时所有相关卡片换色，无法稳定跟踪同一本。此前只验证了排序结果，漏查了这段视觉过程。

另在 1180 × 820 浏览器连续向上拖动时复现：自动滚动让首张卡片移出指针，碰撞目标变为 null，导致松手后顺序回退。

修复：

- 使用独立的不透明拖动层，原卡片隐藏内容、显示落位占位，其他卡片沿用排序过渡。落位动画 180ms，尊重减少动态效果设置。
- 封面色按 workspace 和 notebook ID 保存在本地，排序、重命名和刷新保留原色；首次使用继承当前四种配色。未修改同步数据结构。
- 指针位于卡片列内且超过首尾边界时，保留首尾插入目标，允许自动滚动；横向拖出该列取消。
- 占位层置于其他卡片下方，避免叠放时遮住下一本标题。

验证：

- `outputs/notebook-sort/browser-results.json`：桌面、1180px 与 390px 三种尺寸，叠放／展开／键盘排序、刷新保存、时区设置入口通过。

- TypeScript、触及文件 ESLint、预览及正式构建通过；现有 bundle 大小提示仍在。
