# 网页 Liqui 玻璃模式：实施与验收

日期：2026-09-19。依据 `docs/superpowers/plans/2026-09-19-web-liqui-glass.md`，本次用户已授权实施。网页代码与本机自动验证完成；iPhone 真机、主屏幕 PWA 和网站发布尚未完成。

## 使用

网页「设置与同步 → 外观 → 背景 → 玻璃模式」。旧用户保持原先默认／纸面选择，玻璃模式需要主动开启。同一位置提供「减少透明效果」，偏好仅保存于当前浏览器，不进入便签或云同步数据。

## 已实现

- 手机双入口浮动底栏、官方选中胶囊折射与按压反馈；使用导航按钮与 `aria-current`，支持方向键移动焦点、Enter／空格激活。省去上游搜索及拖动选择功能，取消按压不切换页面。
- 编辑顶栏和格式栏使用一个装饰性玻璃表面，保留原有按钮、编辑器节点和选区处理。320px 下格式栏排列为两行，维持至少 44px 的格式按钮触控面积。
- 设置及配对弹窗采用 Base UI 焦点管理；Portal 挂在应用内部以继承主题。Escape、焦点约束和设置关闭后的焦点恢复已检查。
- 保留原有纸面与烟雾主题；玻璃光学模块按需加载。加载失败、Canvas 不可用或不支持折射时保留可用的毛玻璃／CSS 表面；不支持背景滤镜时用稳定实底。
- 用户／系统减少透明度优先；强制颜色触发降级；减少动态效果会停止正在运行的 JavaScript 弹簧循环以及 CSS 动效。
- 内容区与辅助文字保持深色衬底和便签配色。没有改 Electron 窗口材质、透明侧签坐标、鼠标穿透、数据库或云同步流程。

## 来源与依赖

`@liqui-design/glass@0.3.0`、`@base-ui/react@1.8.0`，React 沿用锁文件中的 19.2.8。已有依赖版本保持原锁定值；仅增加新包及其依赖。

源码参考固定为 Liqui 上游提交 `2cf0eaf1282bb7bb01e4497aa622841c2caed512`。保留官方 lens helper、表面光学参数和 MIT 许可，将 Tailwind 转换为局部 CSS；编辑器按钮沿用原生实现以保留选区逻辑。完整来源及改动说明见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

内核自带有界滤镜缓存，弹窗关闭不强行清空共享缓存；本地观察器、媒体监听与按压动画在组件卸载时清理。桌面可能包含构建产生的可选资源文件，但不会选择网页主题或加载其光学组件。
