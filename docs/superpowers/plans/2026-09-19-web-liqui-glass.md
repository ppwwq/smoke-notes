# 网页端 Liqui 玻璃 UI 接入计划

日期：2026-09-19  
状态：**仅规划，未授权进入本轮实现。** 用户已选定 Liqui 方向，并明确要求先计划。  
范围：烟笺电脑浏览器＋iPhone Safari／主屏幕网页版；Electron 桌面应用留在后续阶段。

## 1. 目标与完成标准

增加可选择的“玻璃模式”：导航、操作栏和弹窗采用 Liqui 的玻璃材质，正文维持清晰可读。

- Chromium 浏览器在支持的环境中呈现边缘折射、高光及轻量按压反馈。
- iPhone Safari 按作者支持策略使用毛玻璃降级；保留层次、标签和可操作性，不承诺同样的背景折射。
- 主题切换、导航和弹窗操作不丢失草稿、编辑选区或保存状态。
- 现有烟雾与纸面模式可恢复；电脑端 Electron 的视觉和便签窗口交互不因共享组件改动而改变。
- 自动检查、浏览器视觉验证和 iPhone 真机验收分别记录，不能互相替代。

这是 2026-09-18 综合计划的**网页阶段细化版**。本阶段的组件选型和设置入口以本文件为准；旧计划中的 Windows Mica/Acrylic 实验、桌面材质设置、整套跨窗口偏好暂不执行。

## 2. 已核实的接入条件

当前提交为 `67e02f5`。工作区现有未跟踪文件来自前几轮研究与计划；产品文件无改动。本轮不安装依赖、不生成产品原型、不改应用代码。

- 共享界面位于 `packages/ui`；网页入口及专属样式位于 `apps/web`。
- 网页背景现在是 `default | paper`，由 `useWebBackground.ts` 本地保存并同步到文档根背景。
- 编辑器为现有 Tiptap 实现，已有精简工具栏、软键盘视口与安全区域适配。
- 当前依赖和 Vite 配置没有 Tailwind。
- Liqui 的完整 registry 组件要求 React 18/19 和 Tailwind CSS v4；官方将组件以源码分发，光学内核单独发布为 `@liqui-design/glass`。[官方 README](https://github.com/leefanv/liqui-design)
- 本轮读取 Tab Bar、Toolbar、Dialog 的官方 registry JSON：都使用 `@base-ui/react` 和 `@liqui-design/glass`；Tab Bar 另含 lens helper，Toolbar 关联 Toggle 的单表面上下文。[Tab Bar](https://liqui.design/r/tab-bar.json)、[Toolbar](https://liqui.design/r/toolbar.json)、[Dialog](https://liqui.design/r/dialog.json)
- 官方 glass 包源码清单标为 0.3.0，导出内核、styles.css、tokens.css。该数字是仓库版本；安装阶段仍应核实 npm 已发布版本并固定实际选用版本。[包清单](https://github.com/leefanv/liqui-design/blob/main/packages/glass/package.json)

## 3. 技术选择

**采用 Liqui 官方光学内核，按需引入并适配组件源码。**

1. 只引入 Tab Bar、Toolbar 和 Dialog 所需源码及辅助代码，保留 MIT 许可与来源说明。
2. 复用官方 `LiquiGlass` 和选中胶囊所需逻辑；组件中的 Tailwind 样式转换为本项目局部 CSS。
3. 保留所需 Base UI 的焦点、键盘与选中状态行为；不复制完整组件目录。
4. 将玻璃颜色、边框和高光变量限定在网页玻璃主题，官方内核样式从网页入口加载；不引入 Tailwind 的全局基础样式重置。
5. 所需包版本与复制的上游提交固定在接入记录中，避免跟随 latest 自动变化。

这需要适配工作，不能当作一条安装命令即可完成。若小样发现源码适配成本明显超出预期，先记录具体阻碍再修订方案，不在执行时悄悄替换成仿制滤镜或整体迁移样式框架。

## 4. 首版视觉范围

| 位置             | 改造内容                                   | 保留的使用方式                       |
| ---------------- | ------------------------------------------ | ------------------------------------ |
| 手机底部导航     | Liqui 浮动圆角底栏、选中胶囊和短暂按压反馈 | “便签／待办”两个入口及文字标签       |
| 网页编辑顶栏     | 轻磨砂与细亮边，清楚区分工具与正文         | 返回、保存状态、保存和更多操作       |
| 格式工具栏       | 一条玻璃表面，上面的按钮保持平面           | 粗体、清单、颜色等原有命令与选区处理 |
| 设置与同步弹窗   | 玻璃面板、适量遮罩、清楚的标题和关闭按钮   | 设置项、配对逻辑、二维码与回收站功能 |
| 便签正文与长列表 | 稳定衬底、适度透光；保留便签色彩区分       | 编辑、选择、滚动和清单               |
| 纸面模式         | 沿用现有实色背景和横线正文                 | 已有字体及荧光标记映射               |

配色先延续烟笺的深灰蓝和便签颜色，不额外引入整套浅色主题。玻璃底栏下方应有实际滚动内容，使模糊与折射有可见背景；不为了展示玻璃加入与笔记无关的动态壁纸。

首版不增加新的搜索入口或重新设计导航信息结构。桌面宽屏网页沿用现有侧栏布局；不能将手机底栏强行复制到宽屏。

## 5. 设置和状态规则

在当前“外观 → 背景”中加入第三项：

- 烟雾模式：现有 default。
- 纸面模式：现有 paper。
- 玻璃模式：新增 glass。

拟扩展 `WebBackground` 为 `default | paper | glass`，继续使用现有浏览器偏好键。未设置或值无效时保持旧默认；已有 paper 用户不被切换。新玻璃模式需用户主动选择。

另提供本地保存的“减少透明效果”开关，保持当前配色但使用稳定实底；兼容浏览器报告的系统减透明偏好。纸面主题始终实色。系统减动态效果关闭装饰形变及弹性运动。

材质优先级：纸面实色 → 用户／系统要求减少透明或强制颜色 → 所选主题的可用材质。若内核加载、Canvas 或滤镜不可用，玻璃模式应仍能显示可读的毛玻璃／实底界面。

主题状态只属于当前浏览器，不写便签内容、数据库或云端同步队列。保存偏好失败时立即应用本次选择并沿用现有提示方式。
