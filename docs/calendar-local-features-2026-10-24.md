# 日历本地功能继续补齐 · 2026-10-24

这轮按用户确认：**月历日期格显示 4 条安排**。保留现有奶油底色、便签本紫色／青柠色、选择控件、抽屉和缩放动效。

## 实现

- 月历按周共享横条轨道：跨天日程连续贯穿日期，到下一周接续，结束日期排他；每个日期显示最多 4 条，超过部分打开当天完整列表。
- 周／日全天区共享同一套跨日条带。带时间的跨夜日程在时间轴继续按当天时段显示。
- 跨天横条可拖动，从中间某天抓取时保留抓取位置相对起始日的偏移。
- 长按 550 ms 或右键行程：查看／编辑、复制这一次。长按日期或时段：新增行程、新增每日待办、粘贴日程。粘贴保留标题、颜色、标签、地点、备注和跨天时长，去除重复规则，先打开可编辑草稿再保存。剪贴板仅当前日历会话内，未操作系统剪贴板。
- 移动超过 8 px 或加入第二根手指取消长按计时；保留原来的触摸拖动和单指滚动。处理新菜单在手指下出现导致的松手误点，下一次主动按下可立即正常使用。
- 行程独立 IANA 时区与持久化查看时区；全天日期不变；旧行程缺省香港。编辑使用原时区，展示与拖动按查看时区换算。详见格式文档的夏令时边界。
- `.ics` / `.json` 规划文件、粘贴内容、下载模板、预览、确认、重复跳过。一次事务导入，失败整批回滚。新类型自动创建，同名复用。未写入任何真实用户计划或外部账号。
- 使用固定版本 ICAL.js 2.2.1 与 Temporal polyfill 0.5.1；解析器延迟加载。完整许可证随两端 public/licenses 提供，原锁定依赖版本没有升级。
